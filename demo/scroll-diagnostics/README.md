# Диагностика отскока

`recorder.js` — отдельный регистратор для уже загруженного `marquee-content` ветки v7, начиная с dev.5. Он читает внутренние поля текущей реализации и не вызывает методы компонента или `preventDefault`.

Текущий регистратор — **v3**: это видно в заголовке панели и в `metadata.recorderVersion`. После замены скрипта обновите страницу и проверьте надпись «диагностика v3».

## На странице, где проявляется ошибка

1. Вставьте всё содержимое `recorder.js` после кода компонента, например в конец JS-панели CodePen. Обновите страницу на iPhone.
2. В появившейся панели нажмите **Начать**. Воспроизведите отскок.
3. Сразу после ложного разворота нажмите **Сбой**. Это ставит отметку и останавливает запись.
4. Нажмите **Скачать JSON** или **Скопировать** и передайте результат для анализа. Если Clipboard API недоступен, появится поле для ручного копирования.

Полезно записать и успешный отскок, остановив запись через экспорт. Для следующей попытки кнопка **Заново** очищает предыдущую запись. При установке скрипта до загрузки компонента дождитесь готовности строки, затем начинайте запись. Состав строк фиксируется при старте; после добавления новой строки начните заново.

## Отдельная страница

Откройте `index.html` через статический HTTP-сервер: страница загружает опубликованный dev.5 с jsDelivr. Для локальной сборки тестовый сервер предоставляет `/diagnostics/?local` и `/dist/index.js`.

На iPhone воспроизводите ошибку в том же браузере и контексте, где она наблюдалась. Отдельная страница полезна для сравнения; CodePen может использовать iframe, поэтому перенос воспроизведения на другую страницу способен изменить поведение.

## Что входит в JSON

- `scrollY`, `pageYOffset`, `scrollTop`, вычисленная граница прокрутки, высоты документа и `visualViewport`;
- события touch/scroll/scrollend/resize с фазой доставки, временем и координатами пальца;
- текущий знак движения строки, направление жеста, защита от отскока, ожидающий разворот и наличие таймера сброса;
- изменения внутренних полей на кадрах, включая сброс таймером без DOM-события;
- User-Agent, возможности ввода, reduced motion, iframe-контекст и адрес загруженного модуля без query/hash.

Фазы `capture` и `bubble` обозначают фазу DOM-события, а не гарантированные снимки до/после обработчика компонента. Порядок регистрации слушателей может отличаться на разных страницах. Кадровый снимок помогает увидеть итоговое состояние.

Запись включается вручную, ограничена последними 2400 записями и хранится только в памяти. Поле `dropped` показывает число вытесненных записей. Текст страницы, поля форм и содержимое строки не собираются; отправки на сервер нет. Активная диагностика добавляет обработчики и чтение геометрии, поэтому может влиять на тайминги. После экспорта все слушатели записи и кадровый цикл отключаются. Удалить панель: `window.marqueeScrollDiagnostics.destroy()`.

Регистратор использует внутренние имена полей компонента; при изменении реализации его потребуется проверить заново. `null` вместо значения поля означает, что оно недоступно.

В v3 записываются `touchViewportDirection`, `lastScrollViewportHeight` и `touchStartedAtBottomEdge`. Последнее поле показывает, начался ли жест у нижнего края страницы, для которого действует защита при изменении высоты окна. Для прежних сборок сохранено чтение `touchStartedAtScrollEdge`. Отсутствующие в сборке поля будут `null`.
